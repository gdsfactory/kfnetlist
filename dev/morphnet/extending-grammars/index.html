Extending kfnetlist.morphnet with New Formats

kfnetlist.morphnet follows a consistent 5-module pattern for every netlist format. To add support for a new format (e.g., myformat), create the following modules under src/kfnetlist/morphnet/netlist/myformat/.

Overview

src/kfnetlist/morphnet/netlist/myformat/
  __init__.py          # empty
  preprocess.py        # text normalization
  transformer.py       # parse tree -> Netlist
  parser.py            # grammar + orchestration
  writer.py            # Netlist -> text

Plus a grammar file:

src/kfnetlist/morphnet/netlist/grammars/myformat.lark

Step 1: Write the Lark Grammar

Create src/kfnetlist/morphnet/netlist/grammars/myformat.lark.

kfnetlist.morphnet grammars use Lark EBNF syntax. The LALR parser is preferred for performance; use Earley only if the grammar is inherently ambiguous.

// myformat.lark
start: toplevel_item*

?toplevel_item: subckt_def
              | instance_stmt

subckt_def: "SUBCKT" IDENT port_decl+ body "END"
// ... define terminals and rules for your format

Every grammar must define a start rule that produces the top-level netlist structure.

Shared terminals (identifiers, SI numbers) can be imported from common.lark:

%import .common.IDENT
%import .common.SI_NUMBER

Tip

Start from an existing grammar as a reference. spectre.lark and spice.lark in src/kfnetlist/morphnet/netlist/grammars/ are good starting points.

Step 3: Implement the Transformer

Create src/kfnetlist/morphnet/netlist/myformat/transformer.py with a Lark Transformer subclass that converts the parse tree into a Netlist model:

from __future__ import annotations

from lark import Transformer

from kfnetlist.morphnet.morphnet_schema import Netlist, Circuit, Port, SubCircuit, Connection
from kfnetlist.morphnet.netlist.net_utils import NetMap, add_port_to_net, net_map_to_connections
from kfnetlist.morphnet.netlist.value_utils import parse_si_number


class MyFormatTransformer(Transformer):
    def subckt_def(self, items):
        # Build a Circuit from the parsed subcircuit
        ...

    def instance_stmt(self, items):
        # Build a SubCircuit from a parsed instance
        ...

    def start(self, items):
        # Assemble the final Circuit
        return Netlist(circuits=..., ext_circuits=...)

The transformer must produce a valid Netlist object — the same protobuf-backed Pydantic model that all other formats use.

Reuse utilities

Use net_map_to_connections from kfnetlist.morphnet.netlist.net_utils to convert net-based connectivity (common in SPICE) to point-to-point Connection objects. Use parse_si_number from kfnetlist.morphnet.netlist.value_utils to parse SI-prefixed parameter values.

Step 4: Implement the Parser

Create src/kfnetlist/morphnet/netlist/myformat/parser.py following the established pattern: a class with a cached Lark instance, a parse() classmethod, and a module-level convenience function:

# src/kfnetlist/morphnet/netlist/myformat/parser.py
from __future__ import annotations

from importlib.resources import files as resource_files
from typing import ClassVar

from lark import Lark

from kfnetlist.morphnet.morphnet_schema import Netlist
from kfnetlist.morphnet.netlist.myformat.preprocess import preprocess_myformat
from kfnetlist.morphnet.netlist.myformat.transformer import MyFormatTransformer


class MyFormatParser:
    lark_instance: ClassVar[Lark | None] = None

    @classmethod
    def get_lark(cls) -> Lark:
        if cls.lark_instance is None:
            grammar_text = (
                resource_files("kfnetlist.morphnet.netlist.grammars")
                .joinpath("myformat.lark")
                .read_text(encoding="utf-8")
            )
            cls.lark_instance = Lark(grammar_text, parser="lalr")
        return cls.lark_instance

    @classmethod
    def parse(cls, text: str) -> Netlist:
        cleaned = preprocess_myformat(text)
        tree = cls.get_lark().parse(cleaned)
        return MyFormatTransformer().transform(tree)


def parse_myformat(text: str) -> Netlist:
    return MyFormatParser.parse(text)

Step 6: Add Tests

Create three test files in tests/:

Parser tests

tests/test_myformat_parser.py — unit tests for parsing individual constructs:

from kfnetlist.morphnet.netlist.myformat.parser import parse_myformat


class TestBasicParsing:
    def test_resistor_subcircuit(self) -> None:
        netlist = parse_myformat("...")
        assert len(netlist.circuits) == 1
        assert netlist.circuits[0].name == "divider"


class TestDeviceTypes:
    def test_mosfet_instance(self) -> None:
        netlist = parse_myformat("...")
        refs = netlist.circuits[0].subcircuits
        assert refs[0].circuit_name == "mosfet"

Writer tests

tests/test_myformat_writer.py — unit tests for writer output on known Netlist objects.

Roundtrip tests

tests/test_myformat_roundtrip.py — roundtrip stability:

def test_parse_write_parse(self) -> None:
    circuit1 = parse_myformat(text)
    written = write_myformat(circuit1)
    circuit2 = parse_myformat(written)
    assert circuit1 == circuit2

Add golden netlist files under tests/netlists/myformat/ for the four standard circuits (rc_lowpass, resistor_divider, hierarchical_subckt, inverter_with_models).

Step 7: Register Exports

Add the new parse and write functions to src/kfnetlist/morphnet/netlist/__init__.py:

from kfnetlist.morphnet.netlist.myformat.parser import parse_myformat
from kfnetlist.morphnet.netlist.myformat.writer import write_myformat

Protobuf Schema Changes

If you need to modify the circuit or simulation protobuf schemas:

  1. Edit the .proto files in crates/kfnetlist-schema/proto/ (the single schema source shared with the Rust core)
  2. Run just compile-schema-py to regenerate the Python bindings, and update crates/kfnetlist-schema/src/convert.rs if the netlist mapping changes
  3. Update the corresponding Pydantic models in src/kfnetlist/morphnet/morphnet_schema/
  4. Run the full test suite to verify nothing broke

Coding Standards

This project follows PEP 8 enforced by Ruff:

  • Line length: 88 characters (Ruff default)
  • Formatting: just format (runs ruff format)
  • Linting: just lint (runs ruff check)
  • Naming: snake_case for functions/variables, PascalCase for classes, UPPER_SNAKE_CASE for constants
  • Type annotations: Required on all public function signatures
  • Testing: pytest with parametrized tests for multi-format coverage
  • No inline comments unless explaining a non-obvious constraint
